# decisions/

**Repo construct ADRs** — decisions about the repo's own structure, conventions, and governance
adoption. Product decisions go in `00-meta-model/` instead.

Naming: `ADR-<SLUG>-META-NNNN-slug.md`. Each states Status, Date, Deciders, Requirement trace,
Context, Decision, Consequences. If a decision genuinely traces to no requirement, record
"none" with the reason rather than omitting the field.
