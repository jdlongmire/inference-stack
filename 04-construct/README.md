# 04-construct/

**MxM** (multi-mode meta-harness) — the repo's own governance surface. `mode.md` at root is the always-loaded doorway;
these are read on demand.

| Surface | Holds |
|---|---|
| `mission.md` | identity, scope, telos — what this is for and what it is not |
| `mind.md` | reasoning disposition — how claims get evaluated here |
| `morals.md` | constraints, gates, what is reserved to the principal |
| `memory.md` | what persists, where, and the flush discipline |
| `methods.md` | tradecraft — the working rules, each traceable to a real failure |
| `means.md` | execution surface — tools, agents, scripts, ops |

Keep each one short. A surface nobody reads governs nothing.
