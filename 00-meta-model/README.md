# 00-meta-model/

**Decisions about the product's own meta-model** — the modeling conventions, taxonomy, and
structural apparatus of *what the repo builds*, kept separate from decisions about the repo's
own construct (those live in `decisions/`). Naming: `ADR-<SLUG>-NNNN-slug.md`.

The separation exists so a product-modeling change and a repo-governance change are never
conflated in one record.
