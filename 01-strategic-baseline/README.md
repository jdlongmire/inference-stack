# 01-strategic-baseline/

**VSOK** — Vision · Strategy · Objectives · Key Results. The *why* and the *what for*.
"Strategic" names the tier's content; the older `enterprise-baseline` named its altitude.

- `1.1-vision/` — what this exists to achieve
- `1.2-strategy/` — the approach chosen, and what was rejected
- `1.3-objectives-krs/` — measurable objectives with key results; PI planning lands here
- `1.4-alignment-references/` — what this inherits by reference rather than restating
